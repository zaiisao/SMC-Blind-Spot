WHAT IS CORRECT (independently re-derived, no action needed)

- Form-1 AR von Mises chain (lines ~287-326 + step_kl vonmises branch). q(phi_t|phi_{t-1},c)=vM(phi_{t-1}+r+delta, kq), prior vM(phi_{t-1}+r, kp), per-step KL is the exact closed form because the vM KL depends on the means only through cos(mu1-mu2). Zero-init of the step head's last layer gives delta=0 and kq seeded at kappa_physical, so the phase KL genuinely starts at ~0.
- Exact categorical marginalisation (462-473). ELBO = sum_c q(c)[recon_c - KL_chain_c] - KL(q(c)||p(c)); log_qc = log_softmax(logits + log_prior) is a reparameterisation, not a bug, and makes q(c)=p(c) at init. Per-component recon is genuinely per-component.
- The closed-form anchor (_anchor_phi0, 265-285). mu0 = -atan2(sum a_t sin(rt), sum a_t cos(rt)) is the exact argmax of sum_t a_t cos(phi0+rt): closed form 2.899553 vs 20001-point grid argmax 2.899690 (grid spacing 3.1e-4). Gradients reach both the evidence head and the rate.
- ar_rate_resid feeds both the rollout and the anchor fold, as documented (428-434, 473, 511).
- Three-way class emission (178-191, 407-413) is a character-faithful port of model.py, and the [B,C,T,3] per-candidate gather was verified elementwise.
- Wrapped-Cauchy density (213-238) is correct and normalised; -H(q) - log p(x) at x~q is an unbiased KL estimator with unbiased pathwise gradients. tempo_step_kl's Gaussian entropy and cross term are likewise unbiased.
- Inverse-CDF von Mises sampler with implicit dS/dkappa (vonmises.py 139-172) — the correct branch, avoiding the recorded -48% Best-Fisher kappa bias at kappa=2.
- Deployment (infer_phase, 499-522) is label-free, eval-asserted, mode-consistent, and the state space stays continuous: the only discrete objects are the rate index and the bar-alignment index.
- No detach() anywhere in the file (unlike model.py:329/414/553/571-572 and variants/psi.py:97/112). pos_weight=1.0, so the recon is a genuine log-likelihood.

WHAT IS AN APPROXIMATION (correct code, false docstring)

A1. The stride kernel is a first-moment-matched (resultant-preserving) von Mises approximation to the S-fold wrapped convolution, NOT the exact marginal. kappa_S = inv_a(A(kappa)^S) matches only the n=1 Fourier coefficient. Monte Carlo at kappa=60, S=8: empirical A2 0.7639 / true A(kappa)^2S 0.7642 vs matched vM's A2 0.7654. At kappa=383, S=8 the discrepancy is KL(true||vM) = 9.0e-6 nats per stride step, ~2e-3 nats per 30 s window — numerically harmless, but the docstring's "nothing about the model's law is approximated" is false.

A2. Deterministic within-stride interpolation replaces a Brownian bridge with a Dirac. The strided objective is a valid ELBO for a DIFFERENT generative model (knot latents + piecewise-linear-phase decoder). Bridge sd peaks at sqrt((S/4)/kappa) = 0.072 rad at S=8 (~11 ms at a 2 s bar). Consequence: stride>1 and stride=1 ELBOs are NOT comparable term-for-term and must never be tabulated together.

A3. gamma = 1/sqrt(kappa) is core matching (Cauchy HWHM = vM sd), not resultant matching (which needs gamma = -log A(kappa) ~ 1/(2 kappa)). At kappa=60: 0.129 vs 0.0084, a 15x looser prior. Swapping vonmises->cauchy at fixed kappa_physical loosens the transition substantially; it is not a neutral tail change.

A4. Laplace stride composition uses sqrt(S) (sd-matching) — the same class of approximation as the vM one, correctly so, but not exact.

A5. The vM sampler draws from a truncated von Mises (support ±min(8/sqrt(kappa), pi)) while step_kl uses the untruncated entropy. ~1e-15 of mass; note it, do not fix it.

BUGS, RANKED BY SEVERITY — all must be fixed before any further run

S1 (blocking). The log_rate clamp (line 368). The bound is technically still valid — w is the latent, the clamp is decoder — but torch.clamp has exactly zero gradient outside the interval, so once log_rate pins at a rail, that step and every later step at the rail deliver no likelihood gradient to mu_w/s_w; only the walk KL pushes back, i.e. purely toward w=0 and never toward better phase fit. This is the project's own recorded absorbing-clamp pathology reproduced verbatim. Fix: either a smooth bounded link (log_rate = lo + (hi-lo)*sigmoid(u), prior expressed on u) or an honest mean-reverting drift. Do not soften it with a hack.

S2 (blocking). ar_phase_kernel='cauchy' AND ar_stride>1 compose the phase prior in von Mises space, giving gamma_S = sqrt(S)*gamma where the wrapped Cauchy requires S*gamma. At kappa=60, S=8: code 0.3542, correct 1.0328 — a factor 2.92 too tight. The file's own tempo_step_kl gets the convention right (S for Cauchy, sqrt(S) for Gaussian/Laplace), so this is internally inconsistent. Any run with both flags is invalid.

S3 (blocking if ar_rate_resid>0). The walk clamp uses the FIXED grid bounds while base = rates*exp(resid) can exceed them, so a positive residual on the top bin is silently discarded at the first walk step — while the anchor fold, computed before the rollout, still used the shifted rate. Anchor and rollout then disagree about the tempo on the edge bins.

S4 (correctness of the mixture KL). The rate log-prior is evaluated at the unshifted grid centres while the likelihood uses the shifted rates. With c=0.05 and sigma=0.3903 the error is up to ~0.3 nats per component at the grid edges, and more fundamentally q's atoms and p's atoms no longer coincide, so sum_c q(log q - log p) is no longer a KL on a common support.

S5 (fragile invariant). kl0 is added outside the q(c) weighting. Correct today only because KL(vM||Uniform) is mu-independent — but in the anchor branch mu0 IS component-dependent, so the invariant is one edit from silently breaking. Return kl0 shaped [B,C] and fold it inside the contraction.

S6. The strided tail extrapolates at the pre-walk rate `rates` rather than the final rate_t, so with ar_tempo_walk the last up-to-S frames advance at the wrong tempo.

S7. The q-increment scale is initialised to walk_sigma*sqrt(S) unconditionally, i.e. the Gaussian convention, so under a Cauchy tempo prior the walk channel does NOT start at KL=0, contradicting the file's stated invariant. (Separately: no Gaussian q can start at KL=0 against a two-component mixture prior at all — see §2.)

S8. ar_rate_resid is silently ignored when rate_posterior != 'categorical'. Assert or log.

S9. Diagnostics only: the per-frame kappa returned under stride is the broadcast stride kappa; within a stride the path is deterministic (kappa infinite). Any "confidence" read off it at stride>1 is meaningless.

S10. Dead code: unused mu_w argument in tempo_step_kl; unused `step` variable in the probe's score().

DESIGN DEFECTS THAT ARE NOT BUGS BUT ARE OUT OF SCOPE UNDER THE PROJECT CONSTRAINT

- ar_phi0_grid: an atomic q against a continuous uniform p(phi_0) with kl0 hardcoded to 0 bounds a different (discrete-initial-condition) generative model, and the circle has no N-fold symmetry the problem supplies. Retire it or relabel every result it produced.
- The 24-bin log-rate grid over [0.020, 0.200] (~10.5% spacing over a decade) is a uniform tiling of a continuous axis, i.e. a discretisation, and in the categorical branch rates_c IS the tempo state. It caps in-tolerance at ~10% while in-tolerance needs ~0.5% precision. ar_rate_resid was the patch and it broke the prior accounting (S4).

D1. Audio-only encoder q(z|x), deployed directly. JUSTIFIED — by VAEBPM_fin §7 only. §7.3.2 states it verbatim ("Our encoder is q_phi(z|x)... the trained encoder is the deployed encoder. No training-inference gap"), §7.8's table sets Encoder=q_phi(z|x), gap "Absent (by construction)". But §11 of the SAME PDF lists (theta,phi,psi), "Encoder input x,b", "Training-inference gap Present", "Sohn's hybrid applies Yes", and phase_qa is unambiguously on the §9/§11 side (c_k = Enc_psi(b,x)). The tutorial contradicts itself; archain follows the earlier side. Nothing to fix in code — fix the framing, and ask which section is normative before claiming fidelity.

D2. Exact enumeration instead of Gumbel-softmax. JUSTIFIED and strictly better. The note's only reason for the relaxation is that arg max has no dT/dpsi; exact marginalisation dissolves that argument and is the zero-variance, zero-bias limit with no temperature anneal. BUT the object enumerated is wrong: a 24-bin log-spaced tiling of a decade is a discretisation of a continuum, not a symmetry class, and in the categorical branch it IS the tempo state — a violation of the binding project constraint. The genuine symmetry classes here are the metrical-level ratio (~4-5 members) and meter (~3), not 24 bins.

D3a. Closed-form circular-mean anchor for phi_0. JUSTIFIED. It is phase_qa Eq. (7)/(10) with the boundary head restricted to a closed form — a legitimate restriction of the variational family, keeping q(phi_0)=vM(mu0,k0) with kl0 = k0 A(k0) - log I0(k0) against uniform. State honestly that _anchor_phi0 sums over the whole window, so it is a GLOBAL alignment estimator, not a boundary condition.
D3b. The phi_0 GRID. UNJUSTIFIED. Atomic q against a continuous uniform prior (infinite KL), kl0 hardcoded to 0, a silent substitution of a uniform-over-N-atoms prior — an ELBO for a different generative model, and a discretisation of the circle.
D3c. "All the mode mass concentrates in the base case." ASSERTED, not derivable. The chain rule guarantees Form 1 is exact for ARBITRARY factors; there is no theorem that unimodal von Mises factors suffice for t>=1 or that residual multimodality lands at k=0. Counterexample inside this model: a half-bar alignment slip at a mid-window tempo break is a genuine second mode no base-case enumeration reaches.

D4. ar_stride. It is a change of MODEL, not of resolution — so the docstring is wrong on both counts. The vM composition is moment-matched, not exact (9.0e-6 nats/step at kappa=383, S=8: harmless, but not "exact"), and the deterministic intra-stride interpolation makes the objective an ELBO of a piecewise-linear-phase model only. Verdict on the practice: acceptable as a declared alternative model; UNJUSTIFIED as presented.

D5. Fixed triangle / three-way truncated-Fourier emission instead of the tutorial's emission Transformer. JUSTIFIED, and the notes supply the reason. NeuralDBN §9.1: Version A "cannot collapse in the emission sense at all — its emission is a fixed window whose only freedom is its width, so it structurally cannot bypass the latent," versus Version B (§9.6's emission Transformer), which faces the milder meaningful-but-bypassed case. §9.5 also warns that lowering a free decoder's capacity is "a matter of degree with no principled setting" — a phi-only closed-form shape escapes that objection because it is a structural constraint, not a dial. Note NeuralDBN §9.2 puts x in the emission while VAEBPM Point 1 forbids it; archain follows VAEBPM, the collapse-safe side. Caveat: even the current FREE Fourier class shapes are too much freedom — the capstone shows the optimizer spends them (+2.12 nats to 2x). The correct move is LESS emission freedom, i.e. further from §9.6.

D6. Heavy tails. The estimator is JUSTIFIED and correct (exact entropy + one-sample cross term, unbiased in value and pathwise gradient), and phase_qa explicitly leaves the conditioning open. But the quoted evidence is rigged: "17490 nats under the shipped Gaussian versus 33 under a Cauchy of the SAME scale" compares two families at a scale fitted for neither. And quantitatively the Cauchy tempo kernel prices a full octave (w = log 2 = 0.693) at 11.6 / 8.8 / 7.4 nats at S = 1/4/8, against 53450 / 13363 / 6681 under a Gaussian of the same scale — a thousandfold cheaper metrical defection, landing in the same 2-10 nat band as every recon difference in the project. The heavy tail and the level-identifiability programme are in direct competition on the same nats scale.

D7a. Dropping per-frame velocity. JUSTIFIED-BUT-UNPROVEN. Defensible at 30 s; archain's own tempo_step_kl docstring gives the reason it is NOT defensible in general ("a ritardando is a PERSISTENT change, so the phase channel cannot carry it — an i.i.d. innovation pays for the same deviation at every step and never learns that the tempo moved"). The arm meant to carry the adaptive-structure thesis is configured below the ~45 s horizon at which a velocity latent would matter, which is precisely why the simplification looks free.
D7b. Dropping the METER coordinate entirely. UNLISTED and more serious. phase_qa fixes z_k = (phi_k, v_k, m_k) and NeuralDBN §9.1 makes the fixed interpretable transition the whole contribution. archain's state is phi alone; grep finds no meter object in the file. Standing memory directive: never hardcode M=4, meter consequential end-to-end. Meter IS a genuine symmetry class of size ~3-4, so it is permitted under the continuity constraint and is the right home for the level identifiability the emission cannot hold.

D8. The log_rate clamp. UNJUSTIFIED — the one place the objective is not a valid ELBO of the model it claims in the honest reading (the density scored is unclamped, the state realised is clamped; the implied kernel has point masses at the bounds). Even on the charitable reading (w is the latent, clamp is decoder) the zero gradient at the rail reproduces the recorded absorbing-boundary pathology.

D9. Inverse-CDF von Mises reparameterisation. JUSTIFIED and faithful — phase_qa Eq. (27) verbatim, and the note's harder correct branch rather than the biased Best-Fisher pathwise one.

PLAIN ANSWER. The project has a valid basis for exactly three departures: the audio-only encoder (§7 authorises it in the professor's own words, though §11 retracts it), exact enumeration over Gumbel-softmax (strictly better, and the note's stated reason for the relaxation dissolves), and the fixed phi-only emission over the emission Transformer (the notes' own collapse analysis argues for it). Everything else departs on poor math or bad experiments. The phi0 grid and the rate grid are ELBOs of different models and violate the project's own continuity constraint; the stride arm silently redefines the generative model while claiming exactness; the clamp is an invalid or degenerate kernel; the deletion of the meter latent contradicts a standing directive with no argument at all; and kappa_physical=383, the constant the whole transition rests on, was derived from a jitter estimate that is rejected on 30-95% of every human corpus and survives only on synthesised grids — and is in any case not measurable in the sweeps, all of which sit inside the noise floor. The departures that are justified are justified; the departures that matter are not.

================================================================
4. RECOMMENDED PAIRING
================================================================

NONE OF THE THREE PROPOSALS SURVIVED. All three were REFUTED under adversarial pricing on real annotations, and the failures are instructive because they are the SAME failure three times: each proposal fitted a MARGINAL statistic and then used it as a PROCESS law.

- Voigt-split (near-deterministic phase kappa=5.1e6, Cauchy-OU tempo). Killed by the OU rate: lambda = 1.15e-3/frame was derived by forcing the AR(1) stationary law onto 0.3903, which is BETWEEN-song tempo spread, not a WITHIN-song reversion rate. Measured on 473 asap files, median |Delta log IBI| by lag is 0.0431 @1 s, 0.0553 @5 s, 0.0688 @17.4 s, 0.0789 @60 s — logarithmic growth, never approaching the asserted half-width 0.2609. Consequences: on a real rubato window the prior prefers a 3x metrical error over the truth by 220 nats before any evidence; on a metronomic slow window it charges 1381 nats for a tempo that does not move (incumbent mixture 160, single Gaussian 3.1). And prediction (c) is a tautology — kappa_q = 1500/0.0171^2 = 5.13e6 = kappa_phi. The honest KL at a deployment-tolerance q is 2.2e8 nats/window, six orders of magnitude worse than today's 312.
- STBP (KL-basis latents phi0, w0, a_1..a_6). Killed twice. The basis is the KL basis of the SHIPPED WALK LAW, a marginal one-frame fit; measured within-window demeaned log-rate variance is 116x (asap343) to 627x (asap254) larger. The true K=6 coefficients cost 515.6 nats (163.5 even at the widest enumerated branch) against a ~7-nat emission — the ELBO's minimiser on any expressive window is a metronome, i.e. the crop-horizon pathology reinstated as a hard analytic prior. And the family does not contain the truth: the ORACLE K=6 projection of the rubato window leaves 1003 ms max / 2.12 rad rms residual, with only 20.4% of frames inside tolerance.
- OU-level archain (tchain kernels + archain anchor). Killed three times. (i) On asap343 the true trajectory scores +788.55 nats of log-prior and a metronome at the same median scores +9480.91 — the prior prefers the metronome by 8692.4 nats, because logmix(0) = +6.886 nats/frame is a bribe for standing still, 15,493 nats over the proposed 2250-frame window, against 157 nats of total emission information. Going to stride=1 and 45 s multiplies that bribe by 3.75x. (ii) The lag-1 autocorrelation cited for the OU (-0.26) is a differencing artifact: measured over 1806 songs the per-bar increment lag-1 autocorr has median -0.450 with 57.4% below -0.4, pinned at the -0.5 MA(1) boundary of annotation jitter, while the proposal's own a = 0.99998521 predicts -7.4e-6. (iii) Fatally for its own test: with r_t = ell*exp(log r_t) and log r_0 free on the line, the likelihood sees only rho = log ell + log r_0, so the recon term cancels exactly in L = log q(ell=1) - log q(ell=2). The pre-registered decisive test reads an observable the emission provably cannot move, and returns the same number in both arms by construction. ell is a redundant reparametrisation, not a symmetry class. Also: the level prior is applied twice (effective sigma 0.276), and "the walk KL starts at 0" is false — KL(N(0,0.0021228^2) || mixture) = 0.6993 nats/frame = 1573.5 nats per 45 s window at init, because no Gaussian q matches a mixture prior.

STRONGEST AMENDED FORM — the intersection of what survived all three critiques. This is a REPAIR SET, not a new model, and it is deliberately conservative: every element is either a deletion of something proven broken, or a constant already in constants.py, or a geometric identity.

Phase prior. p(phi_0) = Uniform(S^1). p(phi_t | phi_{t-1}, r_t) = vM(phi_{t-1} + r_t; kappa_physical = 383), per frame, stride = 1.
  - kappa_physical = 383 is FROZEN and declared not a free parameter, on negative grounds: the WK figure that argued it was 100-1000x too loose is refuted (claim D), and the 383/3000/30000 sweep is inside the noise floor on 4/4 songs (claim E). It is neither measurable from this corpus nor consequential in the sweeps. Do not tune it, do not quote a jitter constant for it. State the consequence openly: at 45 s the prior's free diffusion is sqrt(2250/383) = 2.424 rad.
  - von Mises, NOT wrapped Cauchy. At kappa=383 the two "matched" conventions differ by 15x in one direction (core matching, A3) and ~40x in the other (resultant matching), so no like-for-like comparison exists yet; and the Cauchy prices an octave at 7.4-11.6 nats, inside the recon band. The heavy tail does not belong in the phase channel.
  - stride = 1. This deletes bug class S2 and S6 outright and makes the objective a true ELBO of the per-frame model again (A1, A2).

Phase posterior. Form-1 AR von Mises chain exactly as archain has it, conditioned on the enumerated component: q(phi_0|x,c) = vM(mu0(x,c), k0(x)) with mu0 the closed-form circular-mean anchor (exact argmax, verified 2.899553 vs 2.899690); q(phi_t|phi_{t-1},x,c) = vM(phi_{t-1} + r_t + delta_t, kq_t), delta tanh-capped at DELTA_MAX = 0.35 rad (the cap enters both q and its KL, so it restricts the family without breaking the bound), exact closed-form KL, kq init at softplus^-1(383) so the phase KL starts at 0. KAPPA_Q_MIN 0.01, MAX_KAPPA 1e7 (safety only). Inverse-CDF sampler with implicit dS/dkappa. Optionally kappa_0 = A^{-1}(R) read off the anchor's own folded-evidence resultant rather than regressed — label-free, no fitted head, and it survived all three critiques.
  - ar_phi0_grid DELETED (D3b).

Tempo. This is the channel where nothing survived, and the honest recommendation is to make the minimum valid change and defer the rest.
  - DELETE the 24-bin rate grid, rate_lo, rate_hi, ar_rate_resid and the log_rate clamp. All four are independently condemned: the grid is a forbidden discretisation with a ~10.5% in-tolerance ceiling, the residual breaks the mixture KL (S4), and the clamp is the absorbing boundary (S1).
  - Replace with a single continuous log-rate latent per enumerated component: p(log r_0) = N(TEMPO_PRIOR_MU = -2.6827, TEMPO_PRIOR_SIGMA = 0.3903), corpus fit already in constants.py; q(log r_0|x,c) = N(m,s^2) with the closed-form Gaussian KL. exp(-2.6827) = 0.06838 rad/frame = 1.838 s/bar = 130.6 BPM in 4/4 — a bar-rate fit, as required. Note that sigma becomes consequential for the first time here: under the categorical posterior it was inert by construction (claim F).
  - DO NOT enable any per-frame tempo walk yet. Every walk law on the table is refuted: the single Gaussian is ~80x too thin, the Cauchy hands back the octave (7.4-11.6 nats), the two-component mixture charges 6.886 nats/frame for standing still and prefers a metronome by 8692 nats on real rubato, and the OU's empirical justification is a differencing artifact (median lag-1 -0.450 across 1806 songs). Constant-rate-per-window is the only tempo law not currently refuted at 30 s, and its known limitation (it cannot express a ritardando) is stated rather than papered over. This is the honest position, not a good one — see §6.
  - Consequence to state: this configuration cannot claim anything about rubato or about long songs. It is a 30 s constant-tempo model.

Enumerated set (all genuine symmetry classes, all marginalised exactly). Meter M in {2,3,4}, and bar alignment where the anchor supplies it. Do NOT enumerate a level ratio ell alongside a free continuous log r_0: as the third critique proved, the likelihood sees only log ell + log r_0, the recon cancels across ell, and ell becomes a redundant reparametrisation that charges up to log 5 = 1.61 nats of KL for a label the prior does not model. Either put the whole rate on the continuous coordinate (recommended), or pin the rate per level — but then you have reintroduced the refit the grid deletion was meant to remove.
  q(c) = softmax(logits(x) + log p(c)) so q(c) = p(c) at init and the mixture KL starts at 0. kl0 returned shaped [B,C] and folded INSIDE the q(c) contraction (S5).

Emission. Fixed-shape, phi-only, structured by the enumerated meter. Downbeat channel s_db(phi) = 1 - 2|wrap(phi)|/pi; beat channel the same triangle read at the subdivided phase, s_bt(phi) = 1 - 2|wrap(M phi)|/pi; four parameters total (a, b, a', b'), a = a' = -3.0, b_raw = b'_raw = 1.0 -> softplus 1.3133; Bernoulli, pos_weight = 1.0, target_tol_frames = 0 (do not widen — the widened-target trap).
  - DROP the free three-class truncated-Fourier shapes. The capstone shows the optimizer spends that freedom: the octave gap is +0.04 nats under the binary emission and +2.12 nats FOR 2x once free shapes co-adapt.
  - The beat channel is justified by measured information, not by M. Measured gain (fixed triangle, best-vs-worst rotation, true phase path, valid frames only): asap456 30 s 7.90 -> 23.24 nats; 45 s 15.71 -> 42.49. asap343 45 s 97.32 -> 156.79. asap254 45 s 41.16 -> 123.35. That is ~2.9x, not 4x.
  - Be explicit that this is NOT enough. The affordable per-frame sharpening under a 42-nat budget over 2250 frames is a kappa ratio of 1.331 (sd shrink to 0.87x), while beat tolerance on asap456 is 0.064 rad against 2.42 rad of free diffusion — a required ~31x sd shrink, kappa ratio ~1e3, ~3.2 nats/frame, ~7200 nats. The shortfall is ~190x. The beat channel closes ~0.5% of its own gap. It is the right direction and it is nowhere near sufficient.
  - The beat channel is also NOT level-neutral: on asap343 it is what selects the wrong level (ell=3 beats truth by 13.0 nats in the full joint). Verify sign before shipping it.

Discipline (non-negotiable, and part of the configuration).
  excerpt_seconds = 30.0 for anything claiming a result today (45 s only once a tempo-change prior exists — at 45 s a constant-rate model is a coast, and the metronome bribe scales with T). lr 3e-4, frontend_lr_scale 0.0, pos_weight 1.0. Seeds exposed as argv, >= 3 minimum. Reporting: tail mean ± sd over the last >= 5 snapshots, never a final or peak epoch.

Honest summary of the amended form: it is archain with four deletions (grid, residual, clamp, stride), one substitution (continuous lognormal rate for the grid), one emission restriction plus one emission addition, meter reintroduced as an enumerated symmetry class, and the tempo-change channel switched OFF pending a measurement that does not yet exist. It fixes every proven bug and every proven constraint violation. It does not fix rubato, slow songs, or the amortization gap, and it should not be claimed to.

================================================================
5. THE DECISIVE EXPERIMENT
================================================================

The main open question is NOT which kernel or which kappa. Every kernel comparison on record is inside the noise floor, and every proposal died on the same error. The question is: DOES THE EMISSION SUPPLY ENOUGH PHASE INFORMATION TO PAY FOR ANY POSTERIOR AT ALL? If it does not, every prior repair is irrelevant, because the model cannot tell the truth from a 300 ms displacement or from 2x regardless of what the prior says.

This is CPU-only, training-free, and non-circular. It costs an afternoon and no GPU.

Setup. The ten swept songs, at their exact deterministic 30 s windows, ordered by the corrected difficulty metric (in-window downbeat count): asap254 (5), asap456 (5), asap341 (14), ballroom103 (15), hjdb207 (15), rwc121 (15), hjdb132 (18), hjdb211 (19), asap214 (29), asap169 (33). Parameters PRIOR-INITIALISED — no trained checkpoint. This is what makes it non-circular: the existing kl_budget.py reads kappa_p off the very checkpoint whose behaviour it explains.

Procedure. Evaluate the model's FULL joint log-density log p(y, z) — emission + phase transition + rate prior + meter prior, every term, no omission, no per-candidate rate refit (this is what broke claim C) — on four annotation-derived paths:
  (i) the true path;
  (ii) the true path with a rigid phase offset swept 0 -> pi in 64 steps;
  (iii) the true path at exactly 2x and 1/2x rate, at the pinned true rate;
  (iv) the true path diffused by a random walk reaching 1.97 rad at the window end, >= 32 draws, spread reported.
Run each under two emissions, single-variable ablation, everything else identical: (a) the current free three-class Fourier shapes; (b) the recommended tied downbeat+beat triangle at meter M.

Pass criterion, stated in advance.
  - The tied emission must supply >= 40 nats of phase information across the window (a ~3x margin over the ~12-nat budget a restructured posterior would need, and ~6x the currently measured ~7).
  - The offset profile (ii) must be monotone out to 500 ms with |d log p / d offset| > 5 nats/rad everywhere in that range — no flat region. NOTE the pre-computed number: a wrapped-Cauchy emission at HWHM 0.0171 rad gives only 1.17 nats/rad per downbeat event at 500 ms, so this criterion is met only by aggregating >= 5 aligned events. Report per-event and aggregate separately.
  - The 1x-over-2x margin must be positive on >= 8 of 10 songs with the Monte-Carlo error bar excluding zero.
Under the CURRENT constants the same script must reproduce the known values as a sanity check: <= 2 nats truth-vs-2x margin, a flat offset profile, 312 nats of KL at stride 8. If it does not reproduce those, the script is wrong, not the model.

What falsifies the recommendation. If the tied emission lands in the same ~7-nat band as the free one, then the emission's phase information is not fixable by its DENSITY, the entire relocation of root cause from the prior to the emission's shape is wrong, and the next move is the emission's INPUT — an own evidence head over the 512-dim frontend features — not any further kernel, kappa, or prior work. Equally, if the 1x-over-2x margin is negative or sign-unstable in the tied arm, the level-identifiability framing is wrong and the next move is the amortization gap (IWAE re-pricing of 1x vs 2x under the true marginal likelihood).

Only if this passes does anything go to GPU, and then at >= 3 songs x >= 3 seeds, tail mean ± sd over the last five snapshots. Watch specifically for the ov_stride8 signature: if the level posterior oscillates in sign with period < 20 epochs in BOTH arms, the answer is "optimizer, not objective" and no prior work is indicated.

SECOND EXPERIMENT, if budget allows, because it is cheap and it separates four currently collinear confounds. asap254 and asap456 are perfectly confounded (both below/near the grid floor, both 5 downbeats, both long bars, both sparse beats). On FIXED audio: (1) resample asap456's audio and annotations by 4x — bar rate moves to 0.0736, mid-range; evidence density per bar, annotation sparsity, timbre and rubato all unchanged. If F recovers, it is rate support and/or prior tax and nothing else. (2) Decimate annotations on an easy song — take ballroom103 or hjdb211 and relabel every 4th downbeat as the bar, giving 4-5 bars per 30 s window at a slow bar rate on unchanged audio. That isolates evidence density plus long-bar prior tax with support and annotation quality held good. Two GPU-hours; these two arms alone separate "the model cannot represent this rate" from "there is not enough evidence in the window." Note the answer is partly pre-computed and unfavourable: under N(-2.6827, 0.3903) asap456's true rate sits at z = -3.37, taxed 5.60 nats, while 4x sits at z = +0.18, taxed 0.02 — the level prior prefers the observed 4x lock by 5.58 nats, and a 2.9x emission gain will not overturn it.

================================================================
6. WHAT IS STILL UNKNOWN
================================================================

1. The window-scale tempo process law. Everything in constants.py — WALK_MIX, TEMPO_WALK_SIGMA = 0.00212 — is a fit to the MARGINAL one-frame increment. Measured within-window demeaned log-rate variance is 116x (asap343) to 627x (asap254) larger than sigma_w^2 T/3 implies. No proposal survived because all three laundered a marginal through a process. What is needed and does not exist: a per-window demeaned log-rate variance and coefficient-decay spectrum measured on the corpus, on beat-level intervals, with the linear-interpolation artifact of fit_walk.py removed. Until that exists, every constant tracing to sigma_w is unusable as a process prior.
2. Whether tempo change should be modelled as an innovation on log r (a walk) or on d(log r)/dt (a locally-linear / integrated prior). Real rubato is a correlated ramp — asap343's excursion is 1.998 in log-rate over 1378 frames, 25.4 sd of the driftless walk, or 530x the wide mixture component as a single jump — which is unreachable in any i.i.d.-innovation law however heavy its marginal. Heavy tails buy jumps, not memory. This is the single largest open modelling question and nothing today addressed it.
3. Whether the amortization gap can be closed at all. The encoder reads x only; the optimal potentials are functions of y; the measured potentials are indistinguishable from uniform (entropy 4.564 = log 96, tilt <= ±10%). Whether an x-only encoder can find a tight posterior when the family affordably contains one is untested and is a different question from everything else here.
4. The true value of kappa_physical. It is not measurable from this corpus — WK is rejected on 30-95% of every dataset, and the two corpora where it survives have in-window CV of exactly 0.000000, i.e. synthesised grids. Jitter estimates span 4-57 ms. 383 is frozen because it is unmeasured and inconsequential in the sweeps, not because it is right.
5. Whether the octave defection is a property of the objective or of the optimizer. ov_stride8 defects to 2x at ep250 and walks back to a perfect lock (ratio 1.00, 13 ms, F 1.000) at ep350-399; ov_capstone does the mirror. Both readings remain live and the pricing that would settle it has never been done with an error bar.
6. Whether the ~7-nat emission budget is a property of this frontend's activations or of the emission's density. The tied-emission ablation in §5 answers this and has not been run.
7. Which section of VAEBPM_fin is normative. §7.3.2/§7.8 specify q(z|x) with no training-inference gap; §11 of the same PDF and all of phase_qa specify q(z|b,x) with the gap present and Sohn's hybrid applying. archain follows §7. This needs an answer from the professor, not from us.
8. Whether meter is recoverable at all outside asap and ballroom. Standing verdict: timing-only meter is near chance elsewhere. Reintroducing m as an enumerated latent is right for identifiability bookkeeping; it is not a predicted source of gain.
9. Everything about long songs. The adaptive-structure thesis was relocated onto long songs and rubato; the rubato leg of today's sweep was never rubato (only asap343 qualifies in-window), and no arm has been run at or beyond the ~45 s crop horizon with a tempo-change prior that survives pricing. The thesis is currently untested, not supported and not refuted.
10. Any per-song F ranking. With a p90 adjacent-checkpoint |dF| of 0.344 and every run at seed 0, no per-song ordering in the current logs is measured. The only per-song fact that survives is the in-window downbeat-count ranking, and the only robust behavioural signal is the reproducible ~4x lock on asap254 and asap456.
